# Age Gate — iOS native source (canonical)

These files implement `NativeModules.PeraAgeGate` on iOS using Apple's
`DeclaredAgeRange` framework (iOS 26+). They back the JS `RNAgeGateService`.

**This is the tracked source of truth.** The `ios/` prebuild directory is
gitignored and regenerated by `expo prebuild`, so these files live here (mirroring
the `migration-android/` convention) and the `withAgeGate` Expo config plugin
copies them into the prebuild output and registers them in the Xcode project,
along with the `com.apple.developer.declared-age-range` entitlement.

## Verification needed before release

- Confirm the exact `DeclaredAgeRange` API against the installed iOS 26 SDK in
  Xcode: `AgeRangeService.shared.requestAgeRange(ageGates:)` signature, the
  `.sharing` / `.declinedSharing` response cases, and whether `AgeRange.lowerBound`
  / `.upperBound` are optionals. Adjust if Apple's final API differs.
- The `com.apple.developer.declared-age-range` entitlement must be provisioned on
  the App ID before on-device testing.

## Payload contract (consumed by RNAgeGateService)

`requestAgeRange` resolves `{ status: 'sharing' | 'declined' | 'unknown', lowerBound?, upperBound? }`.
`getDeviceCapability` resolves `'platform'` (iOS 26+) or `'manual'`.
